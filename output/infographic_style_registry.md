# Infographic Style Registry

> Orchestrator가 이미지 생성 전 이 파일을 확인하여 직전 포스트와 다른 스타일을 선택한다.
> 포스트 발행(또는 이미지 생성 완료) 후 Orchestrator가 이 파일을 업데이트한다.
> illustration_1과 illustration_2는 같은 포스트 내에서 반드시 동일 스타일을 사용한다.

## 스타일 키 목록

| 키 | 색감 | 특징 |
|---|---|---|
| `graphic-recording` | 와인+골드+오렌지, 크림 배경 | 핸드드로잉, 교육적, 따뜻한 톤 |
| `modern` | 인디고+시안, 화이트 | 테크/스타트업, 깔끔한 기하 도형 |
| `minimal` | 흑백+회색 | 인쇄 친화적, 최소 장식 |
| `corporate` | 네이비+골드 | 공식 발표, 비교표, 임원급 |
| `bold-data` | 테일+오렌지, 화이트 | 수치 강조, 고대비, 에너지 있는 데이터 시각화 |
| `editorial` | 오프화이트+차콜+테라코타 | 여백 강조, 내러티브, Thought Leadership |
