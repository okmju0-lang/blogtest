## 3줄 요약

1. Anthropic은 MCP를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기부했고, OpenAI와 함께 공동 창립 프로젝트로 올렸다.
2. 발표문에 따르면 MCP는 10,000개 이상의 공개 서버, ChatGPT·Gemini·Microsoft Copilot·VS Code 등 주요 제품 채택, AWS·Google Cloud·Azure 인프라 지원을 확보했다.
3. 공식 Registry, 비동기 작업, 무상태성, 서버 아이덴티티, 확장 기능 등 생태계 운영에 필요한 요소도 빠르게 추가되고 있다.

## 핵심 인사이트

1. **중요해진 이유는 채택 폭**: 한 회사의 실험이 아니라, 여러 제품과 인프라에서 동시에 받쳐주는 공통 규격이 됐다는 점이 핵심이다.
2. **중요해진 이유는 거버넌스 변화**: Linux Foundation 산하로 들어가며 특정 벤더 종속 우려를 낮추고, 장기 표준으로 받아들일 명분이 커졌다.
3. **프로토콜에서 생태계로 이동**: 서버 수, SDK 다운로드, Registry 같은 지표는 MCP가 문서 수준을 넘어 운영 가능한 생태계로 이동했음을 보여준다.

## AX 관련성

- **태그**: 기술트렌드, 거버넌스, 개방형표준
- **관련성 설명**: AX를 추진하는 기업이 특정 벤더 기능이 아니라 장기적으로 재사용 가능한 개방형 표준을 선택해야 하는 이유를 설명하는 근거가 된다.
