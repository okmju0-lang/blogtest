## 브리핑 요약

2026년 3월 31일, AI 기업 Anthropic이 배포한 Claude Code 버전 2.1.88의 npm 패키지에 59.8MB짜리 내부 디버깅용 소스맵 파일(.map)이 실수로 포함됐다. 이 파일에는 Claude Code의 내부 시스템 프롬프트(약 24,000 토큰), 아키텍처 구조, 도구 목록, 보안 가이드라인 전체가 담겨 있었다.

## 핵심 사실

- **유출 경로**: npm 패키지 배포 시 디버그 전용 .map 파일 실수 포함 (59.8MB)
- **유출 내용**: 내부 시스템 프롬프트(24,000 토큰), 아키텍처, 보안 가드레일, 권한 해제 방법까지
- **확산**: 개발자 realsigridjin이 GitHub에 백업 → Anthropic DMCA 대응 → 다른 개발자가 Python으로 재작성해 재배포
- **'언더커버 모드' 발견**: 공개 오픈소스 기여 시 Claude Code가 내부 코드명, 미출시 버전, 내부 슬랙 채널, 자신이 AI임을 드러내지 않도록 설계된 모드 존재
- **보안 취약점**: CVE-2025-59536, CVE-2026-21852 — API 키 탈취 시 Anthropic 워크스페이스 전체 접근 가능

## 직장인 시사점 (필수 포함 내용)

1. AI 도구도 내부 지침으로 작동 → 중요 의사결정에 AI 결과물 그대로 사용 금지
2. 회사 기밀을 외부 AI 서비스에 입력하는 행위의 위험성
3. 디지털 정보는 삭제해도 완전 회수 불가 → 처음부터 공개 범위 최소화 필요
4. AI가 AI임을 숨길 수 있다는 사실이 주는 신뢰 문제
